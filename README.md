This project, known as B-System (BTRON 3.20) and hosted under the MSX-BTRON organization, constitutes a strictly non-commercial, purely educational and scientific computer-science research endeavor. It is a clean-room recreation, implemented entirely in standard C99, of the publicly documented architectural specifications, interfaces, and historical design principles of the BTRON / TRON personal-computer operating environment and related subsystems (including the embedded tronMSX MSX2+ machine model).

The project is undertaken solely for purposes of academic study, historical preservation, technical demonstration, systems research, and the advancement of open knowledge in operating-system architecture, real-time kernels, hypermedia object models, and retro-computing. All source code, documentation, specifications, and artifacts have been independently developed through clean-room methodology.
